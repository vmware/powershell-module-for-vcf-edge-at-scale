ℹ How supervisor sites link to infrastructure sites
  • Each site block below corresponds to a cluster defined in Edge Sites, matched by its Edge Site ID. The PowerShell module joins the two config files on this field — every site must appear in both files with exactly the same name.
  • The network name dropdowns are pre-populated with segments you defined for that site in Edge Sites. The module performs a case-sensitive name lookup when wiring each supervisor network to a vSphere Distributed Port Group.
  • Gateway overrides are optional — leave blank and the module uses the gateway from the matching infrastructure segment automatically.
  • The Supervisor name is generated as {supervisorNamePrefix}-{edgeSite} and also becomes the Kubernetes StorageClass name (lowercased).

Site Name Mismatch

The supervisor.json site names do not match the infrastructure.json cluster names. Map each supervisor site to an infrastructure cluster, or skip it to discard its supervisor configuration.
